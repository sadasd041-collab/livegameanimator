# Original Falling Pickaxe assets

These files were generated for Live Game Animator with the built-in image
generation tool and do not copy the source repository's Minecraft textures.

- `voxel-chasm-v1.png`: portrait-first original voxel canyon background with a
  clear central play corridor, sunset surface, dark cave walls, and cyan crystal
  lighting.
- `crystal-pickaxe-v1.png`: transparent original crystal pickaxe sprite created
  on a flat chroma-key background and processed locally to remove that key.

Both prompts explicitly excluded Minecraft branding, recognizable copied
textures, logos, text, and watermarks.
