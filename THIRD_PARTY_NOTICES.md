# Third-party inspiration and notices

## Falling Pickaxe

The Falling Pickaxe game mode is inspired by the gameplay structure of
[vycdev/falling-pickaxe](https://github.com/vycdev/falling-pickaxe), released
under the GNU General Public License v3.0.

This project does not copy the repository's Minecraft-derived texture PNGs,
audio files, or Python source. Its game background and pickaxe artwork are
new original assets generated specifically for Live Game Animator, while the
following high-level mechanics were adapted: continuous falling, a nine-column
mine, block durability, ore collection, pickaxe tiers, speed modifiers, large
pickaxe power-up, TNT, Mega TNT, camera-impact effects, and livestream chat
commands.
